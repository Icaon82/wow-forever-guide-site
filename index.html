THE PROJECT

정확한 정보가 먼저인 가이드

전체 최적 경로를 보장하는 서비스가 아닙니다. 검증 가능한 데이터가 있는 범위에서만 추천하는 것을 원칙으로 합니다.

01 / LEVELING

조건에 맞는 레벨업 안내

입력한 레벨과 캐릭터 조건을 바탕으로 지역과 퀘스트를 검토할 수 있는 한국어 화면을 준비합니다.

02 / EVIDENCE

출처를 따라갈 수 있는 정보

자료의 출처, 확인 시점, 빌드와 검증 상태를 구분합니다. Classic 참고 정보를 Forever 확정 정보로 바꾸지 않습니다.

03 / SCOPE

필요한 범위의 진행 계획

퀘스트 순서·NPC·이동 동선·직업별 육성 정보는 근거 확보 후 연결할 예정입니다. 미확인 좌표와 선행 조건은 생성하지 않습니다.

DEVELOPMENT STATUS

현재 가능한 것과 남은 일

확인일 · 2026년 11월 10일
  • 구현 · 테스트 완료
    기본 입력 UI와 추천 엔진의 초기 구조

    한국어 입력 화면, 출처 표시, 미검증 정보 제외 로직을 구현했습니다. 현재 개발 버전의 자동화 테스트 59개가 통과했습니다.

  • 소량 참고 자료 연결
    공개 직업 명칭과 지역 참고 정보

    소량의 공개 사실 요약과 링크를 연결했습니다. 지역 목록의 레벨 범위를 검증된 추천 경로로 간주하지 않으며 불일치도 표시합니다.

  • 접근 신청 접수됨
    ForeverDB API 검토 및 접근 승인 대기

    접근 신청을 제출했고 검토 대기 안내로 접수를 확인했습니다. 실제 데이터 API 호출과 API 키 발급은 아직 수행하지 않았습니다.

  • 아직 제공하지 않음
    검증된 상세 퀘스트 동선

    실행 가능한 검증 퀘스트 경로는 아직 없습니다. NPC·좌표·선행 조건을 실제 응답과 근거로 확인한 뒤 단계적으로 추가할 예정입니다.

SOURCES & PRINCIPLES

출처를 섞지 않고, 한계를 숨기지 않습니다.

개인용 도구의 공개 소개 페이지

이 페이지는 프로젝트 목적과 진행 상태를 설명합니다. 가이드 앱 자체와 상세 데이터셋을 배포하는 페이지가 아닙니다. 개인 캐릭터 등록, 완료 퀘스트 기록, 게임 진행 데이터 동기화는 프로젝트 범위에 포함하지 않습니다.

외부 데이터는 이용 조건과 허용 범위를 확인한 뒤 사용합니다. API 접근 승인과 데이터의 재배포 권한은 별도로 판단합니다.

  • ForeverDB.net기본 데이터 출처 · 상세 API 데이터는 승인 이후에만 사용
  • ForeverDB.app보조 검증 출처 · net과 동일 운영 주체인지 미확인
  • Blizzard 공식 안내공식 뉴스 및 개발자 안내 · 발표 범위 내에서 구분하여 참고
FOR DATA PROVIDERS & REVIEWERS

A personal, non-commercial leveling guide.

WoW Forever Leveling Guide is a Korean-language prototype intended to offer evidence-based leveling guidance by faction, race, class, and level range. Its basic UI and recommendation framework are implemented. The API access application has been received and is awaiting review. No API key has been created, no live data API calls have been made, and no verified quest routes are available yet.

ForeverDB.net is the primary data source. ForeverDB.app is a separate secondary validation source; a shared operator or matching data IDs are not assumed. Unverified quest prerequisites, NPC locations, and coordinates will not be invented. This public page is a project overview, not an application or API dataset release.

Data from ForeverDB.net

기본 데이터 출처를 명확히 표시합니다. 상세 API 데이터 이용은 접근 승인 이후에만 진행합니다.

이 프로젝트는 비공식 개인 프로젝트이며 Blizzard Entertainment 또는 ForeverDB의 공식 서비스가 아닙니다. World of Warcraft 및 관련 상표는 각 권리자에게 속합니다.
